# Personal Portfolio Website

This is a personal portfolio website created with HTML, CSS, and JavaScript for college placement purposes.

## Features
- About Me section
- Projects showcase
- Skills list
- Education background
- Contact form (placeholder)

## Usage
Open `index.html` in your browser to view the website.

## Customization
- Update the content in each section of `index.html` with your personal information.
- Modify `style.css` for design changes.
- The contact form is a placeholder and does not send emails.
